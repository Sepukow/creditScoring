# Zadanie 1: własne rozszerzenie kodu

Rozwijamy automatyczny raport monitoringu i porównywania modeli, w szczególności Gini w czasie, PSI, kalibrację, brakujące wartości i opcjonalnie zestawienie z wynikami strategii.

Oddzielamy nasz kod od bazowych narzędzi SAS/Python prowadzącego. Dostarczamy kod źródłowy, przykład zastosowania, wynik i testy. Główna odpowiedzialność: rola D; wsparcie metryk: B oraz integracji: E.
